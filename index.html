aaa

A personal, single-user automation tool.

Private utility · not a public service

What this app does

aaa is a private automation utility built and used by one person, ahuaiab. It connects to Google APIs with the owner's own Google Account to automate repetitive personal tasks: reading and organising the owner's own data, summarising it, and writing results back to the owner's own account.

Google user data

The app requests only the OAuth scopes displayed on Google's consent screen when the owner authorises it, and uses them solely for the functions the owner requests. No Google user data is shared with, sold to, or readable by any third party — see the Privacy Policy.

Who can use it

Only the owner. There is no sign-up, no multi-user access, and no data belonging to anyone other than the owner is ever accessed.

How data is handled

OAuth tokens are stored locally on the owner's own machine. No data is transmitted to any third-party server. Access can be revoked at any time at myaccount.google.com/permissions.
