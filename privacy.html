Privacy Policy

aaa · Last updated: 26 November 2026

This Privacy Policy explains how aaa ("the App"), a personal software tool operated by ahuaiab ("the Operator", "I", "me"), accesses, uses, stores, and protects information obtained through Google APIs.

1. Scope of this App

The App is a private, single-user utility. It has exactly one user: the Operator, using the Operator's own Google Account. It is not offered to the public, has no registration flow, and does not process data belonging to any other person.

2. Information the App accesses

With the Operator's explicit authorisation through Google OAuth 2.0, the App accesses the Google user data covered by the scopes shown on Google's consent screen at the moment of authorisation. The App requests only the scopes strictly necessary for the functions it performs, and never expands that access without the Operator granting new consent.

3. How the information is used

  • To perform the specific automated tasks the Operator requests.
  • To display results back to the Operator within the App.
  • To create or update content only within the Operator's own account.

No information is used for advertising, profiling, analytics, training machine-learning models, or any purpose unrelated to the Operator's direct instructions.

4. Storage and security

OAuth access and refresh tokens are stored locally on the Operator's own device, in a location readable only by the Operator's operating-system account, and are transmitted only to Google's own authentication endpoints over TLS. Data retrieved from Google APIs is held in memory for the duration of a task, or cached locally on the Operator's device where a task requires it. Data in transit is protected by HTTPS.

5. Sharing and disclosure

No sharing. Google user data accessed by this App is never sold, rented, traded, or transferred to any third party. It is never used for advertising. It is never read by any human other than the Operator, who is the only person whose data is involved.

6. Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

  • The Operator may revoke the App's access at any time at myaccount.google.com/permissions. Revoking access invalidates the stored tokens immediately.
  • Deleting the local token file removes all stored credentials from the Operator's device.
  • Locally cached task output can be deleted at any time by the Operator; no copy is retained elsewhere.

8. Children's privacy

The App is not directed to children and does not knowingly collect information from anyone under 13.

9. Changes to this policy

Any material change will be published on this page together with an updated "Last updated" date.

10. Contact

Questions about this policy or about data handling: us@ahuaiab.com
